## Timer Program Example

**Input:**
```text
Enter total seconds: 3665
```

**Output:**
```text
HH:MM:SS : 1 : 1 : 5
```

The program converts total seconds into hours, minutes, and remaining seconds.

## How to Run the Programs

1. Open the project folder in Visual Studio Code.
2. Open the required `.cpp` file.
3. Compile the program using a C++ compiler.

```bash
g++ timer.cpp -o timer
```

4. Run the program on Windows:

```bash
.\timer.exe
```
