# C++ Practical Programs

## About the Project
This project contains basic C++ programs created for college practicals and beginners. It helps to understand classes, objects, attributes, member functions, user input, and basic unit conversions.

## Programs Included

1. **Car Class** – Takes and displays car details using a class and object.
2. **Employee Class** – Takes and displays employee details.
3. **Student Class** – Takes and displays student details.
4. **Inches to Feet Conversion** – Converts inches into feet using a class and object.
5. **Seconds to Time Conversion** – Converts total seconds into HH:MM:SS format.

## Concepts Used

- C++ Basics
- Classes and Objects
- Data Members and Member Functions
- User Input using `cin`
- Output using `cout`
- Mathematical Operations
- Type of Data: `int`, `float`, and `string`

## Requirements

- C++ Compiler (GCC / MinGW)
- Visual Studio Code (VS Code), optional

## How to Run

1. Install a C++ compiler on your computer.
2. Open the project folder in VS Code.
3. Create or open a `.cpp` file.
4. Write or paste the program code.
5. Compile and run the program.

### Compile and Run

```bash
g++ car.cpp -o car
```

Run on Windows:

```bash
.\car.exe
```

Replace `car.cpp` with the name of the program you want to run.

## Example

For the inches-to-feet conversion program:

**Input:**
```text
Enter inches: 36
```

**Output:**
```text
Inches: 36
Feet: 3
```
